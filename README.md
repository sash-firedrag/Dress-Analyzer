#  Dress Analyzer – AI-Powered Fashion Assistant

Dress Analyzer is a stylish, AI-powered fashion assistant built using **React and Vite** that helps users create coordinated outfits and discover their personal style. By uploading images of dresses and accessories, users can receive personalized fashion recommendations generated by **Google Gemini AI**.

The application analyzes visual styling, color coordination, and overall aesthetics to suggest complementary accessories, shoes, hairstyles, and makeup. With Firebase Authentication and a responsive, theme-aware user interface, Dress Analyzer provides a seamless and interactive experience for exploring outfit combinations and refining fashion choices.

##  Features

-  **User Authentication:** Secure sign-in and authentication using Firebase.
-  **Image Upload:** Upload dress and accessory images for AI-powered styling suggestions.
-  **AI-Powered Recommendations:** Generate personalized outfit recommendations using Google Gemini.
-  **Color Coordination:** Explore complementary colors and visually balanced outfit combinations.
-  **Accessory Suggestions:** Get recommendations for shoes, jewelry, handbags, and other accessories.
-  **Beauty Recommendations:** Discover suitable hairstyles and makeup styles to complement an outfit.
-  **Responsive Design:** Enjoy a smooth experience across desktop, tablet, and mobile devices.
-  **Theme-Aware Interface:** Experience a visually polished interface with theme support.
-  **Outfit Refinement:** Explore styling alternatives and improve your overall look.

##  Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js and npm installed
- A Google Gemini API key
- A Firebase project with Authentication configured

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

**2. Navigate to the project directory**

```bash
cd YOUR_REPOSITORY
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the project root and add your API and Firebase configuration using the variable names expected by your application.

Example:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
```

Add any other Firebase configuration variables required by your implementation.

**Important:** Never commit API keys, private credentials, or your `.env` file to GitHub. Variables prefixed with `VITE_` are exposed to client-side code, so do not treat them as secure secrets. For production deployments, protect AI API access through an appropriate backend or serverless function.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

### Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🚀 How It Works

1. **Sign In:** Users authenticate through Firebase.
2. **Upload Images:** Users upload images of their dress and accessories.
3. **Analyze Style:** Google Gemini AI processes the provided visual input to generate styling insights.
4. **Get Recommendations:** The application suggests coordinated accessories, shoes, hairstyles, and makeup.
5. **Refine the Look:** Users explore recommendations and discover outfit combinations that match their desired aesthetic.
